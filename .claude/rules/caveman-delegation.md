# Caveman delegation

When caveman mode is active, write sub-agent delegation prompts (the Task tool prompt) in
caveman too — not only replies to the user.

- Strip fluff: pleasantries, articles, filler, hedging.
- KEEP exact: file paths, identifiers, technical specifics, and multi-step order/structure
  (per caveman Auto-Clarity — never compress a sequence into ambiguity).
- Goal: fewer tokens agent-to-agent, zero loss of substance. If compressing risks misread,
  stay explicit.

When caveman is off, delegate normally.
